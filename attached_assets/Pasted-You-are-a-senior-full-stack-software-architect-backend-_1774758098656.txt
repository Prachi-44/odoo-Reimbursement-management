You are a senior full-stack software architect, backend engineer, frontend engineer, and AI/ML engineer.

Your task is to design and build a complete enterprise-grade Reimbursement Management System (Expense Management System) from scratch with production-level architecture, clean code, scalability, and modular design.

---

# 🧠 PROJECT OVERVIEW

Build a SaaS-based web application where companies can manage employee expense reimbursements with:

- Multi-level approval workflows
- Conditional approval rules (percentage, specific approver, hybrid)
- OCR-based receipt scanning
- Multi-currency support
- Role-based access control
- Admin/Manager/Employee dashboards

This system solves problems like:
- Manual expense tracking
- Lack of transparency
- Delayed approvals
- Complex approval chains

# 🔁 APPROVAL WORKFLOW SYSTEM

Admin defines approval flow:

Example:
Step 1 → Manager  
Step 2 → Finance  
Step 3 → Director  

Rules:
- Sequential approvals
- Next approver gets request ONLY after previous approval
- If rejected → stop workflow

---

# 🧠 CONDITIONAL APPROVAL RULE ENGINE

Support:

1. Percentage Rule:
   - e.g. 60% approvals → approved

2. Specific Approver Rule:
   - e.g. CFO approves → auto-approved

3. Hybrid Rule:
   - e.g. 60% OR CFO approves

Implement logic:
- Dynamic rule evaluation
- Configurable rules per company
